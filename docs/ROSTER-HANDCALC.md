# 六卡手算底稿（AC1）

数据源：`mock/roster.json`（seed=2078，128 行）。页面与 `scripts/check-roster.mjs` 读同一份数据；下表是不经过页面的手算。

## 1. 六卡

| 指标 | 手算公式 | 手算值 | 页面/脚本 |
|---|---|---|---|
| 报名数 | 全部行数 | 128 | 128 |
| 候补数 | status=waitlist | 12 | 12 |
| 待审核数 | status=pending | 7 | 7 |
| 签到数 | checked_in_at 非空 | 96 | 96 |
| 出勤率 | 96 ÷ 128 | 75.0% | 75.0% |
| 非会员数 | is_member=false | 23 | 23 |

## 2. 分项闭合

| 分类 | 行数 |
|---|---|
| 已签到（confirmed 且 checked_in_at 非空） | 96 |
| 已通过未签到（confirmed 且 checked_in_at 为空） | 13 |
| 候补（waitlist） | 12 |
| 待审核（pending） | 7 |
| 合计 | 128 |

校验：96 + 13 + 12 + 7 = 128；已通过 = 96 + 13 = 109；109 + 12 + 7 = 128。四类互斥，无遗漏、无重复。

## 3. 其它对账

- 非会员 23；会员 128 − 23 = 105。
- 已签到 96，出勤率按“签到数 ÷ 报名数”而不是“签到数 ÷ 已通过数”：96 ÷ 128 = 75.0%。
- r020 固定为已通过、已签到、会员，手机号 `13800001234`，用于 AC2；默认显示 `*******1234`。

## 4. 复跑

    node scripts/check-roster.mjs

输出应包含六值对照表、分项闭合、r020 脱敏与 `"ok": true`；失败时 exit 1。
